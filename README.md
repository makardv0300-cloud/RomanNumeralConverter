

# **Римські числа**



Консольна програма мовою C++ для перетворення арабських чисел у римські та римських чисел в арабські. Програма працює з числами від 1 до 3999, підтримує вибір напрямку перетворення та перевіряє коректність введених даних.



**Як зібрати**



1. Відкрити файл `Ir.slnx` у Visual Studio 2026.

2. Обрати конфігурацію `Debug` та платформу `x64`.

3. Виконати `Build → Build Solution` або натиснути `Ctrl + Shift + B`.



**Як запустити**



1. Відкрити проєкт у Visual Studio.

2. Натиснути `Ctrl + F5` для запуску без налагодження.

3. Обрати напрямок перетворення та ввести число.



Програму також можна запустити через файл `Ir.exe`, розташований у папці `x64\\Debug` після збирання проєкту.



**Приклад роботи**



Перетворення арабського числа в римське:



```

Оберіть напрямок перетворення:

1. Арабське число в римське

2. Римське число в арабське



Ваш вибір: 1

Введіть арабське число: 1994

Римське число: MCMXCIV

```



Перетворення римського числа в арабське:



```

Оберіть напрямок перетворення:

1. Арабське число в римське

2. Римське число в арабське



Ваш вибір: 2

Введіть римське число: XIV

Арабське число: 14

```



 Що програма не приймає


- Арабські числа поза діапазоном від 1 до 3999.

- Некоректні римські записи, наприклад `IIII`, `VX`, `IC`.

- Літери та сторонні символи замість арабського числа.

- Порожнє введення.

- Неправильний вибір пункту меню.

- Зайві символи після числового значення.
